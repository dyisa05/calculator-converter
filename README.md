# Calculator & Metric Converter

A simple web app that works as both a basic calculator and a metric converter.

## Features

### Calculator
- Addition, subtraction, multiplication, and division
- Percentage support (e.g. `200 + 10%` = `220`)
- Thousand separators for readability (e.g. `1,234,568`)
- Full keyboard support (numbers, operators, `Enter`, `Esc`, `Backspace`)

### Converter
- Categories: Length, Weight, Volume, Temperature, Time, Area, Speed
- Real-time conversion as you type
- Unit dropdowns update automatically when you change the category

## How to run it

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. That's it — no build steps, no dependencies.
